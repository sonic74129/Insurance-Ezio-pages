# 安责险信息管理平台演示操作手册

## 1. 演示目标

本手册用于由未参与开发的演示人员独立完成以下内容：

1. 展示公共门户、保险产品市场和四类角色工作台。
2. 演示企业投保、保险核保出单、事故预防服务、隐患整改、复查归档和监管数据变化。
3. 演示企业报案、保险更新理赔进度和监管端数据回流。
4. 展示监管驾驶舱、六类专题报表、机构考核、明细下钻和监管简报。

建议使用 Edge 或 Chrome，浏览器缩放保持 100%，窗口建议为 1440×900 或更大。

## 2. 演示前准备

1. 双击仓库根目录的 `start-demo.cmd`。
2. 浏览器打开 `http://127.0.0.1:4173/demo/`。
3. 进入任一账号后，点击右上角用户菜单 → **演示设置**。
4. 载入 **基准数据**。
5. 返回公共门户开始正式演示。

所有账号统一演示密码：`demo123`。

## 3. 建议讲解顺序

### 3.1 公共门户与产品市场

1. 在平台首页介绍“监管、保险、服务、企业”四方协同。
2. 查看平台运行概览和业务数据。
3. 点击 **保险产品**。
4. 说明企业可自主比较多家保险机构和产品，不由平台指定保险公司。

**讲解重点**

- 平台不是单纯网上投保工具。
- 投保、事故预防、隐患整改和理赔数据进入同一业务数据链。
- 公共门户负责公开信息和统一入口，业务办理进入各角色工作台。

## 4. 主流程：投保与事故预防闭环

### Step 1：企业提交投保

1. 点击 **登录平台**。
2. 选择 **生产经营单位 / 企业安全管理员**。
3. 输入密码 `demo123`，点击 **进入工作台**。
4. 查看企业首页中的企业身份、当前保障和待办摘要。
5. 左侧进入 **产品与投保**。
6. 选择人保财险的 **安责险综合保障方案**，点击 **选择并提交投保**。
7. 左侧进入 **保单与服务**，确认申请状态为 **核保中**。

**预期变化**

- 生成新的投保申请编号。
- 保险公司收到待核保通知。
- 企业尚未生成保单。

**讲解重点**

- 投保人数、保费和保额来自企业档案和产品配置。
- 同一企业的申请、保单、服务和理赔使用同一企业编号。

### Step 2：保险公司核保并出单

1. 点击右上角用户菜单 → **退出登录**。
2. 选择 **保险公司 / 保险业务经理** 登录。
3. 左侧进入 **投保核保**。
4. 找到华安新材料有限公司的新申请。
5. 点击 **核保通过**。
6. 左侧进入 **保单与服务**。
7. 找到刚生成的保单，点击 **创建并委托**。

**预期变化**

- 申请状态变为 **已承保**。
- 生成新的有效保单。
- 参保企业数和有效保单数增加。
- 创建事故预防服务任务并委托给安衡服务。

**讲解重点**

- 保险公司独立作出核保决定。
- 服务委托基于有效保单生成，不能脱离保单单独创建。

### Step 3：技术服务机构接单和登记隐患

1. 退出登录。
2. 选择 **技术服务机构 / 服务项目经理** 登录。
3. 左侧进入 **服务任务**。
4. 找到华安新材料有限公司的任务，点击 **接单并派专家**。
5. 再点击 **提交现场结果**。
6. 左侧进入 **隐患与复查**，确认已产生一条重大隐患。

**预期变化**

- 服务任务从 **待接单** 进入 **执行中**，随后进入 **待整改**。
- 系统登记“重大危险源区域联锁报警测试记录缺失”重大隐患。
- 企业账号收到整改通知。

**讲解重点**

- 技术服务机构是独立业务角色，负责方案、现场服务、隐患、复查、回访和归档。
- 隐患记录关联服务任务、企业、责任机构和整改期限。

### Step 4：企业提交整改证据

1. 退出登录并重新登录企业账号。
2. 左侧进入 **隐患整改**。
3. 找到新产生的重大隐患，点击 **提交整改证据**。

**预期变化**

- 隐患状态变为 **待复查**。
- 系统形成整改说明和 3 份模拟证据。
- 技术服务机构收到复查通知。

### Step 5：服务机构复查、回访和归档

1. 退出登录并重新登录技术服务机构账号。
2. 左侧进入 **隐患与复查**。
3. 找到企业已整改的隐患，点击 **复查通过**。
4. 左侧进入 **回访与归档**。
5. 对对应任务点击 **完成回访**。
6. 再点击 **归档**。

**预期变化**

- 隐患状态变为 **已销号**。
- 服务任务依次进入 **待回访**、**待归档**、**已归档**。
- 服务档案完整度为 100%。
- 监管端隐患整改率和服务完成率更新。

## 5. 监管报表演示

1. 退出登录并登录 **监管单位 / 监管业务管理员**。
2. 打开 **监管驾驶舱**。
3. 介绍第一屏 6 个指标：覆盖率、有效保单、保费、服务完成率、隐患整改率、超期重大隐患。
4. 点击任一指标卡或图表条目，展示明细抽屉。
5. 修改地区或行业筛选，观察指标、图表和明细同步变化。
6. 左侧进入 **统计分析**，依次展示：
   - 参保覆盖
   - 保险业务
   - 事故预防
   - 隐患整改
   - 理赔运行
   - 机构考核
7. 在参保覆盖专题展示 **区域 × 行业覆盖矩阵**。
8. 在机构考核页说明评分权重是演示建议口径。
9. 打开 **监管简报**，展示自动结论、投屏版式、打印和 CSV 导出。

**讲解重点**

- 所有指标由当前业务明细实时计算，不是单独写死的数字。
- 图表支持从汇总到企业、保单、服务任务、隐患或赔案明细。
- 报表筛选口径在页面顶部持续显示。
- 监管简报适合会议投屏，并可使用浏览器打印为 PDF。

## 6. 辅助流程：报案和理赔回流

前提：已完成主流程并生成华安新材料有限公司保单。

### Step 1：企业报案

1. 登录企业账号。
2. 左侧进入 **报案理赔**。
3. 点击顶部 **使用保单报案**。
4. 确认生成新赔案，状态为 **已报案**。

### Step 2：保险公司推进理赔

1. 退出登录并登录保险公司账号。
2. 左侧进入 **报案理赔**。
3. 找到新赔案，点击 **推进下一状态**。
4. 可继续点击，依次展示查勘、审核、待赔付、已赔付和已结案。

### Step 3：监管查看回流

1. 登录监管账号。
2. 进入 **统计分析 → 理赔运行**。
3. 查看报案件数、在办案件、状态分布和处理时长。
4. 点击图表进入赔案明细。

## 7. 快速场景

进入任一工作台，点击右上角用户菜单 → **演示设置**：

| 场景 | 适合演示 |
|---|---|
| 基准数据 | 完整主流程 |
| 待核保申请 | 直接从保险核保开始 |
| 待整改重大隐患 | 直接展示企业整改和服务复查 |
| 重大隐患超期 | 展示监管预警和明细下钻 |
| 理赔处理中 | 展示保险理赔和监管回流 |

切换场景会覆盖当前操作记录。正式演示开始前建议重新载入基准数据。

## 8. 演示故障恢复

- 页面数据与手册不一致：进入 **演示设置**，重新载入基准数据。
- 登录身份错误：右上角用户菜单 → **退出登录**，重新选择账号。
- 页面未刷新：按 `Ctrl+R`，LocalStorage 中的业务状态会保留。
- 希望完全恢复：载入基准数据，不需要清除浏览器缓存。
- 本地地址打不开：关闭启动窗口后重新双击 `start-demo.cmd`。
