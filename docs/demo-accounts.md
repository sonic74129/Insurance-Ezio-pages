## 登录说明

1. 打开平台登录页。
2. 点击对应角色账号卡片。
3. 输入统一演示密码。
4. 点击 **进入工作台**。

登录后业务界面不会显示角色切换器。需要更换角色时，点击右上角用户菜单 → **退出登录**，再选择另一个账号。
