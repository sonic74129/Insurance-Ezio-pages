# 安责险信息管理平台离线运行说明

## 1. 推荐启动方式

1. 在仓库根目录双击 `start-demo.cmd`。
2. 浏览器会打开：
   `http://127.0.0.1:4173/demo/`
3. 保持命令窗口开启。
4. 演示结束后在命令窗口按 `Ctrl+C` 停止服务。

启动脚本只使用 Node.js 内置模块，不会安装依赖或访问网络。

## 2. 直接打开

也可以直接使用 Edge 或 Chrome 打开：

`demo\index.html`

页面脚本、样式、图表和数据均为本地文件。推荐使用启动脚本，以便从页面正常打开 `docs` 中的操作手册。

## 3. 浏览器要求

- 推荐 Edge 或 Chrome 的近期版本。
- 建议显示分辨率不低于 1280×720。
- 主验收分辨率为 1440×900。
- 建议浏览器缩放保持 100%。
- 浏览器需要允许 LocalStorage。

## 4. 演示账号

账号清单见 `docs\demo-accounts.md`。统一演示密码：

`demo123`

## 5. 数据保存和恢复

- 操作状态保存在浏览器 LocalStorage 中。
- 刷新页面或重新启动本地服务后，数据仍会保留。
- 进入工作台后，从右上角用户菜单进入 **演示设置**。
- 选择场景并确认后，可以恢复固定数据。
- 切换场景会覆盖当前演示操作。

## 6. 离线能力

以下内容均不需要联网：

- 公共门户和登录
- 四角色工作台
- 监管图表和明细下钻
- 投保、核保、出单和服务委托
- 服务任务、隐患、整改、复查、回访和归档
- 报案和理赔进度
- 场景重置
- CSV 导出
- 浏览器打印或保存 PDF

## 7. 常见问题

### 端口 4173 已被占用

在 PowerShell 中使用其他端口：

```powershell
$env:PORT = 4180
node .\scripts\serve-demo.mjs
```

然后访问：

`http://127.0.0.1:4180/demo/`

### 页面显示旧数据

进入 **演示设置**，重新载入基准数据。数据版本发生变化时，系统也会自动恢复最新 Seed 并显示提示。

### 操作按钮不可用

确认当前登录角色与动作一致：

- 企业：提交投保、提交整改、报案
- 保险公司：核保、出单、服务委托、推进理赔
- 技术服务机构：接单、现场服务、复查、回访、归档
- 监管单位：查看报表、预警、机构考核和简报

### 数据校验

在仓库根目录运行：

```powershell
node .\scripts\validate-demo.js
```

成功时会输出：

`Demo data, reports, scenarios, and cross-role workflows are valid.`

## 8. 对外分发

对外演示时，发送项目生成的精简分享包：

`release\安责险信息管理平台_离线Demo_v1.0.zip`

接收人解压后：

1. 有 Node.js：双击 `start-demo.cmd`。
2. 没有 Node.js：使用 Edge 或 Chrome 直接打开 `demo\index.html`。
3. 打开 `docs\安责险信息管理平台Demo操作手册.docx` 查看完整演示步骤和账号。

Word 操作手册使用组织的 Microsoft Purview `Public` 敏感度标签，不使用 `Confidential` 加密标签。ZIP 不包含 Git 历史、原始调研 Word、规范原文或参考图片。
